## Lead-capture mechanism (honest description)
No backend, no signup, no database. The contact form uses a `mailto:` mechanism: JavaScript builds a pre-filled email (subject: "Mobile detailing quote — Kalamazoo") from the form fields and opens the visitor's own email client. The visitor reviews and sends it themselves. Nothing is stored by this website.
